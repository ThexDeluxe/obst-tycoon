# Obst-Tycoon

Aufbau- und Wirtschaftsspiel für den Browser: Obsthandel mit Straßenverkäufern in einer kleinen Stadt.

Spielen im Browser: https://thexdeluxe.github.io/obst-tycoon/

## Entwicklung

```
npm install
npm run dev       # Entwicklungsserver
npm test          # Tests
npm run build     # Build nach dist/
```

Details stehen in `SPEC.md`, `CLAUDE.md` und `PROGRESS.md`.
